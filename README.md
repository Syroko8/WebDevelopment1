# Web Development I — Repositorio de la asignatura

Repositorio único para los ejercicios y entregas de **Web Development I**. Contiene tanto el material de práctica de los cuadernos como las misiones que se entregan y puntúan en **la Arena**.

### `Cuadernos/`

Ejercicios guiados de cada unidad.
Sirven como material de práctica, **no se suben a la Arena**.

### `Arena/`

Cada subcarpeta corresponde a una misión abierta de la Arena. **Es lo que se entrega y se evalúa.** Cada misión es autocontenida.
